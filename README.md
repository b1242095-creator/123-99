# 星際漫遊｜太陽系模擬器

以原生 HTML、CSS 與 JavaScript 製作的互動式太陽系模擬器。無須安裝套件、建置工具或框架，可直接在瀏覽器開啟，也能部署至 GitHub Pages。

## 功能

- 顯示太陽與水星、金星、地球、火星、木星、土星、天王星、海王星。
- 八大行星沿各自的圓形軌道持續公轉，並以不同顏色、大小和速度呈現。
- 點選軌道上的行星或右側導覽按鈕，可查看行星介紹、日距順序及公轉週期。
- 可暫停或繼續動畫、調整公轉速度，或重設行星位置與速度。
- 深色星空介面與繁體中文內容，並支援一般筆電與較窄的螢幕尺寸。

> 軌道距離與行星大小是方便閱讀的示意，並非實際天文比例；各行星的動畫速度也不代表精確的真實時間尺度。

## 檔案

```text
.
├── index.html   # 網頁內容與介面結構
├── style.css    # 星空背景、軌道、行星與版面樣式
├── script.js    # 行星資料、動畫控制與互動功能
└── README.md    # 專案說明
```

## 使用方式

將這些檔案放在同一個資料夾，直接以瀏覽器開啟 `index.html` 即可。無須安裝依賴，也無須啟動伺服器。

## 操作方式

- 選擇行星：點選軌道上的行星，或在「行星導覽」中選擇名稱。
- 暫停／繼續：使用控制中心的播放按鈕。
- 調整速度：拖曳「公轉速度」滑桿。
- 重設：按下「重設」，將速度與行星位置恢復至初始狀態。

## 部署到 GitHub Pages

1. 將 `index.html`、`style.css`、`script.js` 和 `README.md` 放進 GitHub 儲存庫。
2. 開啟儲存庫的 **Settings → Pages**。
3. 在 **Build and deployment** 中選擇 **Deploy from a branch**。
4. 選擇要部署的分支與資料夾（通常是 `main` 和 `/(root)`），然後儲存。
5. 等待 GitHub Pages 完成部署，再使用 Pages 頁面顯示的網址瀏覽。

本專案使用相對路徑載入 CSS 與 JavaScript，適合部署在 GitHub Pages 的專案子路徑下。
